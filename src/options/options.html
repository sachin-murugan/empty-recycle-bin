"Delete forever" request (one-time setup per module)

This version doesn't use the Freshsales API. It sends the same request the Freshsales screen sends when you delete records forever from the recycle bin, so it needs one example of that request:

  1. In Freshsales, open the module's Recycle Bin and open DevTools (F12) on the Network tab.
  2. Tick one record and click Delete forever (that record is deleted as usual).
  3. In the Network list, right-click the request that appeared, choose Copy > Copy as fetch and paste it below.

Saved requests

    Cookies and the security token in the pasted text are not saved; the extension uses the open Freshsales tab's own session when it runs.
